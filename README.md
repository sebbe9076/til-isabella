# Til Isabella 🤍

En liten bursdagsside – en interaktiv Snoopy-hilsen i fem skjermer.
Bygget med ren HTML, CSS og JavaScript. Ingen rammeverk.

## Filer

| Fil | Hva den gjør |
| --- | --- |
| `index.html` | Struktur + alle SVG-tegningene |
| `style.css`  | Utseende (farger står øverst) |
| `script.js`  | Tekst, skrivemaskin-effekt, skjermbytte, konfetti |
| `img/`       | Bildene som vises på siden |

## Endre teksten

Åpne `script.js`. Øverst ligger objektet `TEKST` – bytt ordene der.

## Kjøre lokalt

```bash
python -m http.server 5177
```

Åpne så http://localhost:5177 i nettleseren.

## Publisering

Ligger på GitHub Pages (`Settings → Pages → Deploy from branch → main`).
